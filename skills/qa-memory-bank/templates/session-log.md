# Session Log

> Append-only. Newest entries on **top** (reverse chronological). One entry per QA session. Keep entries short — the trackers and issues hold the detail.

Template:

```
## YYYY-MM-DD — <handle/session id>
**Pass:** <which tracker(s) you worked on>
**Started from:** <last-run row in tracker, or "retest queue">
**Tested:** <bullet summary>
**Filed:** <issue IDs with one-line title>
**Retests cleared:** <issue IDs verified-fixed | none>
**Blockers:** <if any>
**Next session should:** <one concrete next step>
```
