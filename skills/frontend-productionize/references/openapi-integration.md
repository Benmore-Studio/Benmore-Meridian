## 🏆 Recommended Tool

**`openapi-typescript` v7+ with `openapi-fetch`**

Why this tool?
- Official OpenAPI TypeScript standard (maintained by OpenAPI community)
- Zero runtime overhead - pure TypeScript types
- Best-in-class type inference with discriminated unions
- Minimal bundle size (~2KB)
- Works with any HTTP client
- Active maintenance with weekly updates

Alternative tools (not recommended):
- `orval`: Opinionated about React Query, heavier runtime, verbose output
- `@hey-api/openapi-ts`: Fork with smaller community, frequent breaking changes
- `swagger-typescript-api`: Outdated (last major update 2022)

## Backend Setup (Django)

### 1. Install and Configure drf-spectacular

```python
# backend/settings.py
INSTALLED_APPS = [
    # ...
    'drf_spectacular',
]

REST_FRAMEWORK = {
    'DEFAULT_SCHEMA_CLASS': 'drf_spectacular.openapi.AutoSchema',
}

SPECTACULAR_SETTINGS = {
    'TITLE': 'Your API',
    'DESCRIPTION': 'API documentation',
    'VERSION': '1.0.0',
    'SERVE_INCLUDE_SCHEMA': False,  # Disable Swagger UI in production
    'SCHEMA_PATH_PREFIX': '/api/',
    'OPERATION_ID_PREFIX': '',  # Consistent operationIds
    'COMPONENT_SPLIT_REQUEST': True,  # Separate request/response types
}
```

### 2. Add Schema URL

```python
# backend/urls.py
from drf_spectacular.views import SpectacularAPIView

urlpatterns = [
    path('api/schema/', SpectacularAPIView.as_view(), name='schema'),
]
```

### 3. Test Schema Endpoint

```bash
curl http://localhost:8000/api/schema/
```

## Frontend Setup (Next.js)

### 1. Install Dependencies

```bash
npm install openapi-fetch
npm install --save-dev openapi-typescript
```

### 2. Create Configuration

```typescript
// openapi-ts.config.ts
import { defineConfig } from 'openapi-typescript';

export default defineConfig({
  input: process.env.API_SCHEMA_URL || 'http://localhost:8000/api/schema/',
  output: './src/api/schema.d.ts',
  exportType: true,
  commentHeader: '/* Generated by openapi-typescript - DO NOT EDIT MANUALLY */',
});
```

### 3. Add Environment Variables

```bash
# .env.local
API_SCHEMA_URL=http://localhost:8000/api/schema/
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
```

### 4. Add NPM Scripts

```json
{
  "scripts": {
    "generate:api": "openapi-typescript $API_SCHEMA_URL -o src/api/schema.d.ts",
    "build": "npm run generate:api && next build"
  }
}
```

### 5. Generate Types

```bash
npm run generate:api
```

### 6. Create API Client

```typescript
// src/api/client.ts
import createClient from 'openapi-fetch';
import type { paths } from './schema';

export const api = createClient<paths>({
  baseUrl: process.env.NEXT_PUBLIC_API_BASE_URL || 'http://localhost:8000',
});

export function setAuthToken(token: string | null) {
  if (token) {
    api.use({
      onRequest({ request }) {
        request.headers.set('Authorization', `Bearer ${token}`);
        return request;
      },
    });
  }
}
```

### 7. Create React Query Hooks

```typescript
// src/api/hooks.ts
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { api } from './client';

export function useUsers() {
  return useQuery({
    queryKey: ['users'],
    queryFn: async () => {
      const { data, error } = await api.GET('/api/users/');
      if (error) throw error;
      return data;
    },
  });
}

export function useCreateUser() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: async (body) => {
      const { data, error } = await api.POST('/api/users/', { body });
      if (error) throw error;
      return data;
    },
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['users'] });
    },
  });
}
```

## Usage in Components

```typescript
'use client';

import { useUsers, useCreateUser } from '@/api/hooks';

export default function UsersPage() {
  const { data: users, isLoading } = useUsers();
  const createUser = useCreateUser();

  if (isLoading) return <div>Loading...</div>;

  return (
    <div>
      {users?.map((user) => (
        <div key={user.id}>{user.username}</div>
      ))}
      <button onClick={() => createUser.mutate({ username: 'test' })}>
        Add User
      </button>
    </div>
  );
}
```

## Advanced Topics

### Versioning and Breaking Changes

Track API version in backend:
```python
SPECTACULAR_SETTINGS = {
    'VERSION': '2.0.0',  # Bump major for breaking changes
}
```

Detect version mismatches in frontend:
```typescript
const EXPECTED_VERSION = '2.0.0';

api.use({
  onResponse({ response }) {
    const backendVersion = response.headers.get('X-API-Version');
    if (backendVersion && backendVersion !== EXPECTED_VERSION) {
      console.warn('API version mismatch detected');
    }
    return response;
  },
});
```

## Best Practices

1. **Commit Generated Types**: Commit `schema.d.ts` to Git for CI/CD compatibility
2. **Run Before Build**: Always generate types before building: `"build": "npm run generate:api && next build"`
3. **Version Control**: Track schema changes in Git to detect breaking changes
4. **CI Validation**: Add CI check to verify schema is up-to-date
5. **Error Handling**: Implement consistent error handling across all API calls
