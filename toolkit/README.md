# Development Toolkit & Setup Guide

Get your development environment up and running with all essential tools.

---

## 📋 What's Included

This guide helps you install and set up:

- **Core Development Tools** - Terminal, package managers, search tools
- **System Utilities** - Window management, productivity apps
- **Version Control** - Git and GitHub CLI
- **Deployment Platforms** - Vercel, Heroku, and others
- **External Services** - Sentry, Cloudinary, Email, AI APIs
- **Internal Tools** - Portal and team resources

## 🔧 Tool Categories

### Core Development Tools
- **ghostty** - GPU-accelerated terminal
- **tree** - Directory structure visualization
- **uv** - Ultra-fast Python package manager
- **ripgrep (rg)** - Fast recursive search
- **Rust** - Programming language & ecosystem

### System Utilities
- **Rectangle** - Window management (macOS)
- **Raycast** - Productivity launcher

### Version Control & Deployment
- **GitHub CLI** - Version control management
- **Vercel** - Frontend deployment
- **Heroku** - App hosting & deployment

### External Services & APIs
- **Sentry** - Error tracking & monitoring
- **Cloudinary** - Image & media management
- **Mailjet** - Email service
- **Gemini** - Google's AI API

### Internal Tools
- **Portal** - Project management system
