Development Toolkit Checklist

Project: Dev Onboarding [BEN-2001]

Key Takeaways
  • Complete development environment setup for new team members
  • Covers core tools, system utilities, version control, deployment platforms, and external services
  • Includes quick setup script for automated installation
  • Verification commands for each tool
Core Development Tools
ghostty
GPU-accelerated terminal emulator
brew install ghostty
tree
Directory structure visualization
brew install tree
uv
Ultra-fast Python package manager
brew install uv
ripgrep (rg)
Fast recursive search
brew install ripgrep
Rust
Programming language
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
System Utilities
Rectangle
Window management for macOS
brew install rectangle
Raycast
Productivity launcher
brew install raycast
Version Control & Infrastructure
GitHub CLI
Command-line interface for GitHub
brew install gh

Then authenticate: gh auth login

Deployment Platforms
Vercel
Frontend deployment
npm install -g vercel && vercel login
Heroku
App deployment
brew install heroku && heroku login
External Services & APIs

Error tracking

Create account, store API credentials in .env

Quick Setup Script

Save the following as setup-tools.sh and run to install all tools at once:

#!/bin/bash
echo "Installing development toolkit..."
brew install ghostty tree uv ripgrep rectangle raycast
brew tap homebrew/cask && brew install heroku
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
brew install gh && gh auth login
npm install -g vercel
echo "Setup complete!"

Run with: bash setup-tools.sh
