Django Production Checklist

Time: 45-60 minutes | Django 5.0+ | Python 3.11+

  • 14-phase comprehensive production setup for Django projects
  • Covers tools, security, Docker, CI/CD, monitoring, and testing
  • Uses uv for fast Python package management
  • All items should be checked before production deployment

Production Criteria
Phase 1-3 -- Foundation
1
Install Core Tools
10 min
uv (Python package manager), tree, Make, gitleaks, Git, Docker
2
Setup Project Structure
5 min
Create directory, init git, create .gitignore
3
Setup Python Environment
5 min
Create venv with uv, install dependencies, add core and dev deps
Phase 4-6 -- Configuration
4
Copy Config Files
5 min
pyproject.toml, Makefile, .pre-commit-config.yaml, .env.example
Dockerfile, docker-compose.yml, CI workflow
5
Security Setup
10 min
Create .env, generate SECRET_KEY, set DEBUG=False
Scan for secrets with gitleaks
6
Django Settings
10 min
Create settings directory (base / dev / prod / test)
Configure INSTALLED_APPS, test with --deploy flag

7
Structure Verification

Testing

Makefile Validation

13
CI/CD Pipeline

Monitoring

Production Ready Criteria
  • ✓ make check-all passes in less than 30 seconds
  • ✓ Pre-commit hooks configured and passing
  • ✓ Test coverage >=80%
  • ✓ No secrets in git (gitleaks clean)
  • ✓ Django deployment check passes (--deploy flag)
  • ✓ Docker image builds and services healthy
  • ✓ CI/CD pipeline passes on GitHub
  • ✓ Health check endpoint responds 200 OK
  • ✓ Sentry monitoring configured
  • ✓ Environment variables documented in .env.example
Quick Command Reference
Command Purpose
make install Install all dependencies
make dev Start Django dev server
make test Run all tests
make check-all Run all checks (<30s)
gitleaks detect --source . Scan for secrets
docker build -t myapp:latest . Build Docker image
docker-compose up -d Start all services
